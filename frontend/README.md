# Frontend – Ganglbauer Zeitmanagement

Vue 3 (`<script setup>`, JavaScript) mit Vue Router, Pinia und Vite.

```bash
npm install
npm run dev      # http://localhost:5173, /api wird an http://127.0.0.1:8000 weitergeleitet
npm run build    # Produktions-Build nach dist/
npm run lint     # ESLint
npm run format   # Prettier
```

Aufbau und Hintergründe: siehe [`docs/Dokumentation.md`](../docs/Dokumentation.md).
